# Tools & Tech Stack

## Game Development
- **Game Engine**: Phaser.js 3 (HTML5, JavaScript)
- **Mobile Wrapper**: Capacitor 5 (wraps web app as native iOS/Android)
- **iOS Build**: Xcode + Fastlane (requires Mac)
- **Language**: JavaScript (ES2020+), no TypeScript unless requested
- **Bundler**: Vite (fast dev server + build)

## AI & Agents
- **Agent Runtime**: Anthropic SDK (`@anthropic-ai/sdk`)
- **Model**: `claude-sonnet-4-6` (default), `claude-opus-4-6` for complex design tasks
- **Image Generation**: OpenAI DALL-E 3 via `openai` npm package
- **Memory System**: ABC-TOM (markdown files in `agents/` directory)

## Infrastructure
- **Messaging**: Telegram Bot API (`node-telegram-bot-api`)
- **Webhook Server**: Express.js (Node.js)
- **Hosting (Portal)**: GitHub Pages (free, auto-deploy via GitHub Actions)
- **Repository**: GitHub (`liranz10/dev-stuff`)
- **CI/CD**: GitHub Actions

## Game Project Structure (per game)
```
games/{game-name}/
├── src/
│   ├── scenes/         ← Phaser Scene classes
│   ├── assets/         ← images, audio (generated by Art Agent)
│   └── main.js         ← Phaser game config + scene registry
├── index.html
├── vite.config.js
├── capacitor.config.json
└── package.json
```

## API Keys Required
- `ANTHROPIC_API_KEY` — Claude agents
- `OPENAI_API_KEY` — DALL-E 3 image generation
- `TELEGRAM_BOT_TOKEN` — Telegram bot

## Commands Reference
```bash
# Dev server for a game
cd games/{name} && npm run dev

# Build for web
cd games/{name} && npm run build

# Sync to iOS (requires Mac + Xcode)
cd games/{name} && npx cap sync ios && npx cap open ios

# Start Telegram bot server
cd telegram-bot && node index.js
```

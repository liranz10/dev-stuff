# טיסת הכוכבים ✈️⭐

**🎮 לשחק:** https://star-flight-dun.vercel.app (באייפד: Safari ← שיתוף ← הוספה למסך הבית)

משחק טיסה לגילאי 5 שמשחקים בסלון. אייפד אחד מנהל את הטיסה, והמשפחה עושה הכול בשביל אמיתי: יושבים בכיסאות, חוגרים, אוכלים וקופצים במערבולת. על המסך כמעט אין מילים. המשחק אומר בקול, במשפט קצר, מה עושים.

1. **מי טס?** לוחצים על אמא, אבא, יובל, עלמה, סבתא או סבא. רק אנשים אמיתיים.
2. **לאן?** בוחרים יעד לפי תמונה ודגל: פריז, לונדון, רומא, אילת, קניה, תאילנד, טוקיו או ניו יורק.
3. **עלייה למטוס:** כל נוסע מקבל כיסא עם צבע וציור, והדיילת מראה לו את הכיסא האמיתי.
4. **חגורות, קליק!** ואז סופרים יחד 3, 2, 1 וממריאים.
5. **הטיסה:** מפה עם המטוס שזז במסלול האמיתי, דגל גדול של הארץ שמתחתינו, גובה וזמן שנשאר. כשעוברים לארץ חדשה המשחק אומר את זה בקול. יש שני כפתורים: 🍽️ זמן לאכול (הדיילת מגישה באמת) ו-🌪️ מערבולת (קופצים על הכיסא).
6. **נחיתה:** כולם מוחאים כפיים, ואז רואים את הדגל, איך אומרים שלום שם, ועובדה קצרה. אפשר לטוס הביתה 🏠 או ליעד חדש ✈️.

הטיסה במשחק קצרה: בין דקה וחצי לחמש דקות, לפי המרחק האמיתי. 🔁 בפינה חוזר על המשפט האחרון, ו-🔊 משתיק.
**דף הדפסה** (קישור במסך הפתיחה): שלטים צבעוניים לגב הכיסאות וכרטיסי עלייה.

## איך זה בנוי
אין שלב בנייה ואין שרת: `index.html`, `style.css` ו-`js/*.js` (מודולים). `sw.js` שומר את הקבצים כדי שהמשחק יעבוד גם בלי אינטרנט.
`js/world.js` נוצר מ-`tools/make-world.mjs` (מפת Natural Earth עם שמות ודגלים בעברית). `js/geo.js` מחשב את המסלול, מה נמצא מתחת למטוס, את הגובה ואת זמן הטיסה.

פרויקט Vercel בשם `star-flight` עם Root Directory `flight`. הענף הראשי של המאגר הוא לא הענף של המשחק, אז פריסת Production נעשית ידנית מהענף `claude/flight-game`.

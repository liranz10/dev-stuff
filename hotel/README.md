# מלון הכוכבים ⭐🏨

משחק מלון לגילאי 5, לכמה אייפדים ביחד: כל מכשיר הוא תחנה אחרת במלון, וההזמנות עוברות ביניהן.

**🎮 לשחק:** https://star-hotel.vercel.app (באייפד: Safari ← שיתוף ← הוספה למסך הבית)

| תחנה | מה עושים |
|---|---|
| 🛎️ קבלה | חיות מגיעות עם מזוודה ומבקשות חדר (לפעמים בצבע מסוים). בוחרים מפתח מלוח המפתחות, ובסוף אומרים להתראות ואוספים כוכבים |
| 🧳 אורחים | הילד או הילדה בוחרים חיה ושם, מקבלים חדר ומזמינים בעצמם אוכל וניקיון. אפשר גם ללכת לישון, לתלות שלט "לא להפריע", לדבר בטלפון עם הקבלה ולדרג את המלון |
| 🧑‍🍳 מטבח | הזמנות נתלות על המסילה. מוצאים את האוכל במזווה, מבשלים במחבת, בתנור או בסיר, מכסים את המגש ודופקים בדלת |
| 🧹 ניקיון | משחקונים: לנגב אבק באצבע, לסדר מיטה, לקפל מגבות, לזרוק לכלוך לפח |
| 📺 מסך המלון | כל הבניין בגדול, טוב לטלוויזיה או למחשב: מי בכל חדר, מה הזמינו, כוכבים וחדשות |

- **לא צריך לקרוא:** הכול באייקונים, בצבעים ובקול בעברית. כל חדר מזוהה בצבע ובסמל (🌸 ☀️ 🐟 🌳 ❤️ 🌙).
- **המלון גדל:** עם הכוכבים מגיעים פרסים: גינה, מזרקה, בריכה, בלונים, מגלשה, קשת, זיקוקים וכתר.
- **משחק פיזי:** אחרי משימות מופיעות משימות אמיתיות בבית, כמו לקפל מגבת או להביא מגש עם אוכל צעצוע. בהגדרות להורים יש דף להדפסה עם שלטי דלת לחדרים בבית, כרטיסי מפתח ותפריט.
- **כמה מכשירים:** כולם צריכים אותו מספר "חדר משפחתי" (במסך הפתיחה). אפשר לשחק גם במכשיר אחד ולעבור בין התחנות. תחנה שאף אחד לא משחק בה מתבצעת "בקסם", ואורחים דמיוניים מגיעים לבד.
- **הגדרות להורים:** לוחצים לחיצה ארוכה על "⚙️ להורים": 4 או 6 חדרים, אורחים דמיוניים, קצב, משימות אמיתיות, קול, מוזיקה והתחלה מחדש.

## איך זה בנוי

- אין שלב בנייה: `index.html`, `style.css` ו-`js/*.js` (מודולים) מוגשים כמו שהם. `sw.js` שומר אותם כדי שהמשחק יעבוד גם בלי אינטרנט.
- `api/hotel.js`: פונקציית Vercel שמחזיקה את המלון של כל חדר משפחתי ב-Redis (Upstash), כשקית של מסמכי JSON קטנים. בכל מסמך יש גרסה, והכתיבה החדשה ביותר של כל מסמך מנצחת.
- בלי מסד נתונים (או כשפותחים את הקובץ ישירות) המלון נשמר רק במכשיר, ולשוניות באותו מכשיר מסתנכרנות ביניהן.

## העלאה ל-Vercel

פרויקט Vercel בשם `star-hotel`, עם Root Directory `hotel`. כדי שכמה מכשירים ישחקו ביחד צריך לחבר מסד נתונים, פעם אחת:
ב-Vercel ← הפרויקט `star-hotel` ← **Storage** ← לבחור את מסד הנתונים של Upstash שכבר קיים (זה של עיר הבובות) ← **Connect Project**. אחר כך **Redeploy**.
